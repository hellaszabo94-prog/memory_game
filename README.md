## English

### Overview

Memory Game is a browser-based card matching game built with HTML, CSS, and vanilla JavaScript.

The goal of the game is to find all matching card pairs. The cards are shuffled randomly whenever the game starts.

### Features

* Random card shuffling
* Eight matching card pairs
* Card flip animation
* Pair matching logic
* Temporary board locking while cards are checked
* Automatic win detection
* Responsive game layout
* Custom-designed card backs

### Technologies

* HTML5
* CSS3
* JavaScript ES6
* Git
* GitHub
* GitHub Pages

### Live Demo

[Open the live demo](https://hellaszabo94-prog.github.io/memory_game/)

### How to Play

1. Click on a card to reveal its image.
2. Click on a second card.
3. If both cards match, they remain visible.
4. If they do not match, they are turned back over.
5. Find all matching pairs to complete the game.

## Deutsch

### Übersicht

Memory Game ist ein browserbasiertes Karten-Memory-Spiel, das mit HTML, CSS und Vanilla JavaScript entwickelt wurde.

Das Ziel des Spiels ist es, alle zusammengehörenden Kartenpaare zu finden. Die Karten werden bei jedem Spielstart zufällig gemischt.

### Funktionen

* Zufälliges Mischen der Karten
* Acht zusammengehörende Kartenpaare
* Animation beim Umdrehen der Karten
* Logik zur Überprüfung der Kartenpaare
* Vorübergehende Sperrung des Spielfelds während der Überprüfung
* Automatische Erkennung des Spielendes
* Responsives Spiellayout
* Selbst gestaltete Kartenrückseiten

* Git

[Live-Demo öffnen](https://hellaszabo94-prog.github.io/memory_game/)

### Spielanleitung

1. Klicke auf eine Karte, um das Bild anzuzeigen.
2. Klicke anschließend auf eine zweite Karte.
3. Wenn beide Karten übereinstimmen, bleiben sie sichtbar.
4. Wenn die Karten nicht übereinstimmen, werden sie wieder umgedreht.
5. Finde alle Kartenpaare, um das Spiel abzuschließen.
